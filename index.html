쓰는 법

세 번이면 내 웹앱에서 움직입니다

  1. 1모션을 누릅니다

    썸네일을 누르면 창이 열리고 큰 화면으로 움직임을 확인할 수 있어요.

  2. 2내 것에 맞춥니다

    창 오른쪽 ‘문구’에서 글자를, ‘설정’에서 비율·속도·이미지를 바꿉니다. 안 바꿔도 됩니다.

  3. 3복사하거나 영상으로 저장합니다

    ‘프롬프트 복사’를 눌러 AI에게 붙여 넣고 넣을 자리만 한 줄 적어 주세요. 영상이 필요하면 ‘영상으로 저장’을 누릅니다.

영상으로 만들기

‘영상 소스’ 조각을 mp4로 뽑는 법

AI가 영상을 직접 만들어 주는 것은 아닙니다. AI가 화면을 그리는 코드를 짜고, 브라우저가 그 화면을 1초에 30장씩 찍고, ffmpeg가 이어 붙여 mp4로 만듭니다. 여기 있는 모션은 전부 ‘t초일 때의 한 장면’을 그리는 코드라서 이 방식에 그대로 맞습니다.

가장 쉬운 길: 창에서 바로 저장

  1. 모션을 눌러 창을 열고, 위쪽 비율 단추로 크기를 고릅니다. 인스타 캐러셀은 4:5(1080×1350), 릴스·스토리는 9:16(1080×1920)입니다.
  2. 오른쪽 ‘문구’에서 글자를 내 것으로 고칩니다. 미리보기에 바로 반영됩니다.
  3. 영상으로 저장 (mp4)를 누릅니다. 길이(초)만큼 30fps로 찍어 파일로 내려받습니다. 한 바퀴가 딱 맞게 돌도록 길이가 미리 들어 있어요.

컴퓨터의 크롬·엣지에서 됩니다. 만드는 동안 창을 그대로 두세요. 장면 여러 개를 따로 저장해 인스타그램 캐러셀에 한 장씩 올리면 움직이는 카드뉴스가 됩니다. 소리는 들어가지 않습니다.

AI에게 맡기는 길

  1. ‘영상 소스’에서 장면을 고르고 프롬프트 복사를 누릅니다. 영상으로 뽑는 순서가 프롬프트 안에 들어 있습니다.
  2. Claude Code처럼 내 컴퓨터에서 명령을 돌릴 수 있는 AI에 붙여 넣고, 글자와 길이(초)를 적어 줍니다.
  3. AI가 장면 파일을 만들고 한 장씩 찍어 mp4로 묶습니다. 여러 장면은 따로 뽑아 이어 붙이면 됩니다.

직접 할 때 쓰는 명령

npm i playwright && npx playwright install chromium
# 장면을 열고 seek(초)를 부르며 한 장씩 저장한 뒤
ffmpeg -framerate 30 -i frames/frame_%05d.png -c:v libx264 -pix_fmt yuv420p -crf 18 -movflags +faststart out.mp4
# 목소리 넣기
ffmpeg -i out.mp4 -i voice.wav -c:v copy -c:a aac -b:a 192k -shortest out_audio.mp4

화면 크기는 가로 영상 1920×1080, 쇼츠 1080×1920. 복사한 코드의 qmEngine(…)이 돌려주는 값에 seek(초)가 있습니다.

해외에서 통하는 요령

  • 장면마다 시간을 숫자로 적습니다. “2번 장면(4~5초): 제목이 올라온다”처럼요. 남는 시간에 무엇을 할지도 적어야 멈춘 화면이 안 생깁니다.
  • 화면에 나올 글자는 따옴표로 묶어 줍니다. 안 묶으면 AI가 말을 바꿉니다.
  • 색, 글꼴, 움직임 곡선을 먼저 정해 둡니다. “보라색 그라데이션 금지, 그림자 카드 금지” 같은 금지 목록도 한 번 적어 둡니다.
  • 전체를 뽑기 전에 처음·중간·끝 세 장을 먼저 찍어서 봅니다. 오류가 없다고 보기 좋은 것은 아닙니다.
  • 고칠 때는 한 번에 하나만, “밝기 35%쯤”처럼 숫자로 말하고 “구도와 움직임은 건드리지 마”를 붙입니다.
  • 찍기 전에 글꼴이 다 불러와졌는지 기다리게 합니다. 안 그러면 첫 장면 글자가 깨집니다.

다른 길도 있습니다. HeyGen HyperFrames는 HTML로 영상을 짜는 무료 도구(Apache 2.0)이고, Remotion은 React 기반으로 가장 널리 쓰이지만 4인 이상 조직은 유료 라이선스가 필요합니다. 둘 다 Claude Code용 스킬이 공개돼 있습니다. 위 내용은 2026년 10월 해외 문서와 튜토리얼을 조사해 정리한 것입니다.

자주 묻는 질문

복사한 것을 어디에 어떻게 붙이는지

프롬프트, 코드, HTML 파일은 어떻게 다른가요?

‘프롬프트’는 클로드 코드 같은 AI에게 그대로 붙여 넣는 부탁 글이고, 코드가 그 안에 들어 있습니다. 넣을 자리만 한 줄 적어 주면 돼요. 직접 붙일 때는 ‘코드’를, 새 페이지로 쓸 때는 ‘HTML 파일’을 복사해 .html로 저장합니다.

라이브러리를 따로 설치해야 하나요?

아니요. 필요한 코드가 HTML 한 덩어리 안에 다 들어 있어서 붙여 넣기만 하면 움직입니다. 3D·배경의 입체 모션만 three.js를 불러오는 한 줄이 코드에 함께 들어가는데, 그것도 설치할 것은 없어요. 영상(mp4)으로 뽑을 때만 Playwright와 ffmpeg가 필요합니다.

내 이미지는 어떻게 넣나요?

카드 쇼케이스와 휴대폰·책 목업은 ‘내 이미지’에서 파일을 고르면 미리보기에 바로 보입니다. 코드에는 images/파일이름으로 적히니, 같은 파일을 내 사이트의 그 폴더에 올려 두세요.

글자나 색은 어디서 바꾸나요?

키네틱 타이포는 설정의 ‘글자’ 칸에 낱말을 쉼표로 나눠 적으면 바로 바뀝니다. 그 밖의 글자·숫자·날짜는 복사한 코드의 ‘② 모션’ 맨 위에 모여 있습니다. 색은 ‘① 설정’의 colors: [...] 여덟 칸을 밝은 색부터 고치면 전체 색 계열이 바뀝니다.

ThreeUI 원본 모션은 어떻게 쓰나요?

창 위쪽에 ‘ThreeUI’라고 적힌 모션은 HTML 파일 하나가 통째로 모션입니다. ‘HTML 파일’을 복사해 .html 파일로 저장한 뒤, 내 페이지에서 <iframe src="저장한파일.html">로 불러오면 됩니다. MIT 라이선스라 자유롭게 쓸 수 있지만, 파일 맨 위의 저작권 고지는 지우지 말고 그대로 두세요.

한 페이지에 여러 개를 넣어도 되나요?

서로 다른 모션이면 그대로 여러 개 붙여도 됩니다. 같은 모션을 두 번 넣을 때만 id="qm-…" 이름을 서로 다르게 고쳐 주세요. 모션은 화면에 보일 때만 움직입니다.

새로 들어온 것

들어온 순서대로 적어 둡니다

  • 문구 고치기와 영상 저장

    창 오른쪽 ‘문구’에서 장면의 글자를 바로 고칠 수 있습니다. 고친 내용은 복사되는 코드에도 들어가요. ‘영상으로 저장’을 누르면 그 장면을 mp4로 내려받습니다. 인스타 캐러셀용 4:5, 릴스용 9:16 크기로 나옵니다.

  • 영상 소스 50종

    코드로 영상을 만들 때 장면으로 쓰는 조각입니다. 타이틀, 자막, 전환, 차트, 화면 시연, 주석까지. ‘영상으로 만들기’ 안내도 함께 넣었어요.

  • 글자 16종을 새로 짰습니다

    해외 라이브러리 아홉 곳의 소스와 수상작 사이트의 수치를 조사해, 가림막 안에서 올라오는 줄·글자 풀림·플랩 보드 같은 표준 효과로 다시 만들었습니다.

  • 수업·기록 14종을 문구 느낌으로

    방안지 체크리스트, 주간 플래너, 라벨 프린터, 메모 패드처럼 일본 문구에서 가져온 모양으로 전부 바꿨습니다.

  • 3D 장면 10종

    등고선, 하프톤 정물, 모빌, 별 궤적, 실 그림 같은 새 장면을 넣고 리퀴드 크롬과 노을은 뺐습니다.

  • 키네틱 타이포 13종, 카드 쇼케이스 12종, UI 모션

    큰 글자가 주인공인 포스터형 모션과, 내 이미지를 넣어 돌리는 쇼케이스, 알림·버튼·차트 조각입니다. ThreeUI 공개판(MIT) 원본도 버튼·글자·배경 종류에 함께 들어 있습니다.
