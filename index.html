    FAQ

    먼저 물어볼 것들.

    복사한 코드를 어디에 어떻게 붙이는지 정리했습니다.

    프롬프트, 코드, HTML 파일은 어떻게 다른가요?

    ‘프롬프트’는 클로드 코드 같은 AI에게 그대로 붙여 넣는 부탁 글이고, 코드가 그 안에 들어 있습니다. 넣을 자리만 한 줄 적어 주면 돼요. 직접 붙일 때는 ‘코드’를, 새 페이지로 쓸 때는 ‘HTML 파일’을 복사해 .html로 저장합니다.

    라이브러리를 따로 설치해야 하나요?

    아니요. 필요한 코드가 HTML 한 덩어리 안에 다 들어 있어서 붙여 넣기만 하면 움직입니다. 3D·배경의 입체 모션만 three.js를 불러오는 한 줄이 코드에 함께 들어가는데, 그것도 설치할 것은 없어요.

    내 이미지는 어떻게 넣나요?

    카드 쇼케이스와 휴대폰·책 목업은 ‘내 이미지’에서 파일을 고르면 미리보기에 바로 보입니다. 코드에는 images/파일이름으로 적히니, 같은 파일을 내 사이트의 그 폴더에 올려 두세요.

    글자나 색은 어디서 바꾸나요?

    키네틱 타이포는 설정의 ‘글자’ 칸에 낱말을 쉼표로 나눠 적으면 바로 바뀝니다. 그 밖의 글자·숫자·날짜는 복사한 코드의 ‘② 모션’ 맨 위에 모여 있습니다. 색은 ‘① 설정’에 colors: [...]를 밝은 색부터 8개 넣으면 전체 색 계열이 바뀝니다.

    ThreeUI 원본 모션은 어떻게 쓰나요?

    이름 위에 ‘ThreeUI’가 붙은 모션은 HTML 파일 하나가 통째로 모션입니다. ‘HTML 파일’을 복사해 .html 파일로 저장한 뒤, 내 페이지에서 <iframe src="저장한파일.html">로 불러오면 됩니다. MIT 라이선스라 자유롭게 쓸 수 있지만, 파일 맨 위의 저작권 고지는 지우지 말고 그대로 두세요.

    한 페이지에 여러 개를 넣어도 되나요?

    서로 다른 모션이면 그대로 여러 개 붙여도 됩니다. 같은 모션을 두 번 넣을 때만 id="qm-…" 이름을 서로 다르게 고쳐 주세요. 모션은 화면에 보일 때만 움직입니다.
